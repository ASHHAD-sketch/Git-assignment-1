Question #1

Types of Version Control Systems

  1. Local Version Control System (LVCS)
  2. Centralized Version Control System (CVCS)
  3. Distributed Version Control System (DVCS)

Read each scenario and select the most suitable Version Control System with a short reason.

1. Small Website

Answer: Local Version Control System (LVCS)

Reason: A single developer working on one computer can use a local system to track changes in the website files.

2. Learning Management System (LMS)

Answer: Centralized Version Control System (CVCS)

Reason: A centralized system allows team members to share files and manage changes through a central server.

3. Large-Scale Gaming Software

Answer: Distributed Version Control System (DVCS)

Reason: Each developer has a local copy of the project and can work independently before sharing changes with the team.
